## 一、压力机制速通

### 杏仁核 vs 前额叶
- 杏仁核（保安）：压力越大越激活，负责警报
- 前额叶（CEO）：压力越大越下线，负责理性思考
- 结果：压力越大，智商下降，理性说服无效

### 三个关键认知
1. 毒性复原力：社会推崇的"硬撑"其实有毒
2. 压力悖论：都以为只有自己有压力，不敢谈反而更孤独
3. 任何变化都是压力：积极变化也是压力

## 三、五次重置 + 你的行动方案

### 第三次重置：身心合一

核心：用生理手段调节压力

播客方法：
1. 呼吸训练：478呼吸法、腹式呼吸
2. 运动：每日20分钟散步是黄金方案
3. 饮食：肠道是第二大脑，95%血清素在肠道合成

你的行动方案：
- 呼吸：每天3次478呼吸法（吸气4秒-憋气7秒-呼气8秒，每次4组）
- 运动：骑车40分钟+做操20分钟（已够）
- 饮食：18:00晚饭（已固定），午餐别吃太饱

478呼吸法适用场景：
- 上班烦躁时做一组，立刻冷静
- 躺下睡不着做两组，容易入睡

### 第四次重置：专注当下

核心：从焦虑拉回现在

播客方法：
1. 间隙休息：每工作一段时间，3-5分钟纯休息
2. 消灭多任务：单线程处理
3. 模拟通勤：用仪式感切换身份
4. 粘脚训练：脚趾张开扎根地面

你的行动方案：
- 填30分钟知识库 -> 站起来看窗外3分钟 -> 再继续
- 别一边填知识库一边焦虑工资低，一次只做一件事
- 骑车上下班本身就是天然的身份切换仪式
- 烦躁时脚趾用力张开贴地，30秒见效

### 第五次重置：摆脱自责（最重要）

核心：停止自我攻击

播客方法：
1. 感恩清单：每日手写5件小事，阻断消极回路
2. 治愈性写作：写感受和故事，释放情绪
3. 一日一生：每日兼顾玩乐、工作、闲暇、独处

你的行动方案：

【感恩清单】每天睡前写5件感恩的小事：
1. 今天骑车路上_____
2. 今天吃了_____
3. 今天完成了_____
4. 今天让我开心的一件事_____
5. _____

不需要宏大，越小越好。例如：
- 今天骑车路上风很舒服
- 今天中午的饭挺好吃的
- 今天填了50条知识库
- 今天21:00放下手机了
- 今天同事说了一句暖心的话

【区分事实和故事】
事实：今天上班没什么活干
故事：我在浪费人生，我好废
把故事扔掉，只看事实

【允许自己不怎么样】
缓解压力不是减少压力，是放气。你不需要每天都很充实。
